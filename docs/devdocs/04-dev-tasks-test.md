## 核心验收用例

### IT-001：F第一天接口与预检收口

按[F第一天审核稿](04-dev-tasks-f-day1.md#9-it-001-审查签认与验收顺序)核对任务owner/依赖/测试、字段类型及范围、RFID桥板级路由、权限矩阵、SQLCipher/IPC、错误码和验收顺序；F文档审定已按用户授权记录，D/Z/L签认及B-01～B-07预检/发布风险仍待收齐和处置。密码协议/参数、模块类型号或硬件字段未确定时记录阻塞，不能仅凭文档存在记PASS。

通过：无未裁决的接口冲突，签认完整；预检失败均有负责人、修复路线及截止日。安全功能实机通过情况另由对应IT/E2E判定。当前状态：待签认/待预检，不改变下方追溯矩阵的“待执行”。

### E2E-001：刷卡至用户会话

1. 桥板使用项目签发测试身份建立经过认证的 PBR AEAD 会话。
2. 真实 RC522 产生事件；Pi 验证 tag、bridge_id、boot_id 和 event_id。
3. Pi 短暂使用 raw UID，计算本机密钥派生索引。
4. 页面只显示低敏 PIN 页；输入正确 PIN 后打开当前用户会话。

通过：未认证/重放/过期事件拒绝；PIN 前不读用户数据；raw UID 不落盘/日志。

### IT-012：SQLCipher跨用户隔离

用户 A/B 各写一条不同标记；以 A context 读取 B、以错误 key 打开 B DB、退出后重用旧 session。

补测锁屏：旧前台API/历史查询拒绝，已启动任务只能追加A的记录且不显示敏感内容；A任务未收尾不能切至B，收尾后迟到事件不得进入B。检查旧盆栽JSON写入禁用、旧无归属记录未擅自导入/删除，worker不能直接读取旧文件。

通过：所有越权读取和错误 key 均失败；用户文件使用 SQLCipher；DB/WAL/log/temp 无 PIN、raw UID 或明文健康记录。

### IT-014：模块业务数据加密和认证

**LAN**：抓取链路，注入无TLS TCP、错误设备证书指纹、过期会话、TLS 协商失败。通过条件：自签证书 + `peerCertificate().digest(Sha256)` 与 TrustStore 登记值一致才算通过；指纹不符立即断开返回 `IDENTITY_REJECTED`；**无明文回退**。

**BLE**（两层都要验）：
1. 链路层——未配对（`pairingStatus!=Paired`）时 `writeCharacteristic` 被拒，返回 `TRANSPORT_SECURITY_REQUIRED`。
2. 应用层——已配对但挑战-响应失败时，**业务数据不得交给模块**；连续 3 次失败断开。
3. 抓包不得恢复传感器明文或凭证；不得出现「已配对即放行」的旁路。

**通用**：任何错误均不回退旧明文协议；单条业务 payload 超 512 字节被拒（`INVALID_MESSAGE`）；lane 热切换后未经重新认证的数据被拒。

### IT-013：基础worker隔离

以 worker UID 启动模块代码，尝试读取 DB、Pi主目录、任意文件和公网地址；再令 worker 崩溃并观察宿主。

通过：DB/密钥/任意文件访问拒绝；无公网路由；worker崩溃不带崩宿主，资源被回收。验证 Pi 实机规则生效，不只检查配置文件。

### E2E-004：啸天真实两路输入

两对真实探头分别遮挡/恢复，观察去抖、每路 event_id 和页面状态。

通过：两路互相独立、无串线；P0不将速度精度、户外距离或闭合围界列为通过项。

### E2E-006：双模块同时运行

同时连接盆栽与啸天；持续接收盆栽全部传感器数据（确认LAN TLS/BLE加密和身份认证）并交替触发啸天两路；拔出一槽后观察另一槽。

通过：业务按device/session/task/origin-user不串；slot仅位置属性。拔槽释放槽位但原安全有效无线任务继续；桥重启不重启有效业务，新物理绑定重新认证并且不转移授权。

补测：拔出后原模块无线任务继续、物理槽释放；新设备占旧槽不继承旧任务/历史，迟到事件不更新新设备。桥板USB掉线时已有有效业务继续、位置unknown；拒绝新刷卡/绑卡/物理接入确认，但允许本机PIN解锁查看本人任务、停止和撤权。桥恢复重验控制身份/位置，匹配则恢复位置不重启业务，冲突则拒绝新绑定不转移旧授权；业务TLS/认证失效仍停止对应任务。

### Journey-001：完整P0旅程

```text
桥板项目测试身份认证
→ 两个模块分别认证
→ 用户刷卡并通过PIN
→ 盆栽全部数据可见
→ 啸天两路真实输入可见
→ 两模块同时运行
→ 拔出一个槽
→ 另一槽继续工作
→ 用户锁屏：旧前台API拒绝，原任务仅可追加原用户数据
→ 任务完成/显式停止后退出：全部旧会话/任务API拒绝
```

任一步骤身份、授权、SQLCipher、worker沙箱、事件路由或实机验收失败，P0 即不通过。
