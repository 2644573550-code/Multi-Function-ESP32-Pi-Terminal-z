任务依赖主图

箭头表示前置任务必须完成或接口冻结后，后续任务才能进入正式集成验收。

两周关键阻塞：SQLCipher 用 C API（不走 Qt 驱动，已定）；worker需从QLibrary同进程加载迁出；LAN TLS(自签+指纹固定)与BLE(配对+应用层挑战)必须实装，禁止明文回退；啸天两对探头第3天前到货；双槽电气必须证明支持并发。不得用普通SQLite、同进程插件、GPIO模拟、明文数据或“分别运行”替代硬性验收。

P1｜安全产品化

SQLCipher备份/恢复、生产桥板密钥生命周期、完整systemd/network sandbox、域名代理和撤权断网。

P1｜模块扩展

双槽长期稳定、啸天测速/户外、正式安全NFC、血压计和电量遥测。

P2｜长期任务

OTA、版本回滚、SDK发布、量产维修/密钥恢复、适老化和可访问性。
