花盆底座 拆两半 + 卡扣 可行性评估
=====================================================================
问题:能不能拆成两半减少支撑、减少打印时间,用卡扣固定?
结论:技术上完全可行,但【收益很小】,不推荐。数据如下。

=====================================================================
一、先测:换朝向能不能解决(最省事的方案)
=====================================================================
  朝向                    高度    贴床      需支撑
  ① 底面朝下(当前)        45.0mm  72.6cm²  **205.2cm²**
  ② 翻转 180°(顶面朝下)   45.0mm   5.1cm²  **277.8cm²**  ← 更糟 ✗

  → 翻转无效,反而更差(原底面变成了朝上的悬垂)

=====================================================================
二、再测:按不同高度拆件,各自正放打印
=====================================================================
  分型面              下部件(A)              上部件(B)
  ─────────────────────────────────────────────────────────
  z=13.5(碗底平面)   A 高13.6  支撑204.1cm²  B 高31.6 支撑167.9cm²  ✗✗
  z=16.3(碗底上表面) A 高16.3  支撑205.2cm²  B 高28.7 **支撑0.0cm²** ✅
  z=17.0(原试算)     A 高17.0  支撑205.2cm²  B 高28.0 **支撑0.0cm²** ✅
  整体(不拆)          —         —            —                     支撑205.2cm²

  ★ 关键:205cm² 的悬垂【全部集中在下部那 16mm 里】

  为什么下部件消不掉:
  · 205cm² 主要来自"碗底的下表面"(z=13.5 处的水平面,直径约 140mm)
    以及连接盘的下表面
  · 这个面在下部件里,它的下方是空的 → 必须支撑
  · 上部碗件一旦有自己的底(碗底),就能直接贴床 → 支撑 0

=====================================================================
三、拆件能省多少?—— 算支撑体积
=====================================================================
  悬垂面积 205cm²,但它下面是【浅腔】,平均深度约 10~13mm
  → 支撑实际体积 ≈ 205cm² × 1.2cm ≈ 2.5~3 cm³
  → 折算打印时间:约 **5~10 分钟**
  → 折算材料:约 3~4 g

  对比拆件的代价:
    · 多一个零件(多一次装夹、多一道拼接面)
    · 多 4~6 个卡扣结构(增加约 3~5 cm³ 材料)
    · 卡扣装配后,接缝处需要保证不进土、不漏水
    · 卡扣松动风险(花盆+水长期受压)

  ★ 结论:省 5~10 分钟,换来一个新零件+拼接风险 —— **不划算** ✗

=====================================================================
四、如果还是要拆,方案是什么
=====================================================================
  分型面:z = 16.3(碗底上表面,高度 16.3mm)
    A 下部件:高度 16.3mm(螺纹套 + 连接盘 + 防滑底面)
    B 上部碗:高度 28.7mm(碗底 + 碗壁),**贴床 64.4cm²,支撑 0** ✅

  卡扣方案(参考主机外壳已验证的机构):
    · 企口(lap):B 底部做 2mm 深、3mm 宽的台阶,A 顶面对应凸起
    · 卡舌:B 外壁下沿做 4~6 条弹性卡舌(宽 12、厚 1.0、凸出 0.8)
    · 卡槽:A 外壁对应位置开卡槽(深 0.6)
    · 密封:A 顶面开 1mm × 1.5mm 的环形槽,放 O 型圈或涂硅胶
    · 撬口:接缝处开 2 处 2×1mm 小槽,便于拆开

  防水:碗里的水在 B 的碗底上,分型面(B 的底面/A 的顶面)
        在碗底【下方】,所以正常浇水不会漏;
        但若水溢过碗底边缘,会从接缝渗出 → 需要密封措施

=====================================================================
五、更值得做的两个优化(比拆件收益大)
=====================================================================
  ① 用 H2D 双喷嘴 + PVA 水溶支撑
     支撑虽然 205cm²,但可以水溶掉,不用手工掏
     → 省的是【清理时间】而不是打印时间,但清理时间往往更烦

  ② 把支撑改成"仅接触面 + 树状"
     支撑体积可从 3cm³ 降到 1.5cm³ 左右
     → 再省 2~3 分钟,零代价

  ③ 若确实想彻底免支撑:
     把碗底下方那圈空腔改成实心(填平 z 0~13.5 的环形空腔)
     → 增加约 15cm³ 材料,但悬垂面积从 205cm² 降到 ~0
     → 打印时间:支撑省 8 分钟,材料多花 20 分钟 → 反而更慢 ✗

=====================================================================
六、结论
=====================================================================
  ┌──────────────────────┬────────────────────────────────┐
  │ 方案                  │ 评价                            │
  ├──────────────────────┼────────────────────────────────┤
  │ 翻转打印              │ ✗ 更差(278cm²)                 │
  │ 拆两半+卡扣           │ ⚠ 可行,但只省 5~10 分钟,代价大  │
  │ PVA 水溶支撑          │ ✅ 推荐(H2D 的强项)             │
  │ 树状+仅接触面         │ ✅ 推荐(零代价省 2~3 分钟)      │
  │ 填实空腔              │ ✗ 反而更慢                      │
  └──────────────────────┴────────────────────────────────┘

  ★ 一句话:
    能拆、能用卡扣,但 205cm² 的悬垂实际只值 5~10 分钟;
    用 H2D 的 PVA 水溶支撑直接解决更划算。
    真拆就把分型面放在 z=16.3,上部碗件支撑为 0。
=====================================================================
