Cone_Case ↔ 花盆底座 螺旋配合 复检报告
=====================================================================
结论先行:
  ✅ CC 本体【顶部】有螺旋(实测),这是给 CC 自带盖子用的
  ✗ CC 本体【底部】无螺旋(光滑锥面)
  ✗ 花盆底座【无螺旋】(光滑锥孔)
  → 所以:花盆底座和 CC 之间【目前不能螺旋安装】
  → 但可以做:只改花盆底座(CC 不动,已打印的 CC 完全可用)

=====================================================================
一、CC 本体顶部螺纹(实测参数)
=====================================================================
  检测方法:在 0° / 90° / 180° / 270° 四条母线上,每 0.5mm 高度打射线取外径

  z(mm)     0° 半径   180° 半径   差值
   68.0     69.10     67.85     +1.25   ← 牙顶/牙底
   68.5     69.10     67.85     +1.25
   69.0     67.86     67.85     +0.01   ← 同高
   70.0     67.86     69.09     -1.23   ← 相位反转(说明是螺旋)
   71.0     67.86     69.08     -1.22
   72.0     67.86     67.86     +0.01
   73.0     69.10     67.85     +1.25
   ...
   78.0     69.08     67.86     +1.22

  ★ 关键证据:同一高度上 0° 与 180° 的半径【周期性地一高一低】,
    且高低分布在 90°/270° 方向上错开 → 这是螺旋面,不是多边形

  提取到的螺纹参数:
    牙深(半径方向)     1.24 mm
    牙径范围            Ø135.72 ~ Ø138.20
    轴向重复周期        ≈ 4.8 mm(0° 母线 r 跳变:3.4mm + 1.4mm 交替)
    螺纹段高度          z 68.0 ~ 79.5(约 11.5mm 长)
    旋向                右旋(半径随 z 上升的相位方向)

  用途:CC 自带盖子旋在这段螺纹上(盖子内部有对应内螺纹)

=====================================================================
二、CC 本体底部:无螺纹
=====================================================================
  z 0~12 四条母线半径差仅 +0.01~0.02mm(完全对称)→ 光滑锥面 ✗

=====================================================================
三、花盆底座:无螺纹
=====================================================================
  z 36~45 内孔半径:
    z=36  84.32/84.28    z=40  85.78/85.75    z=44  86.02/86.00
    四条母线差值 0.03~0.05mm → 光滑锥孔 ✗(只是一个 1:4 左右的锥度)

  孔口尺寸:内孔 Ø164.4(r=82.2),外径 Ø173(r=86.5),壁厚 3.3mm,高 45mm

=====================================================================
四、为什么现在装不上
=====================================================================
  CC 顶部螺纹直径  :Ø135.7 ~ Ø138.2
  花盆底座内孔直径:Ø164.4
  → 相差 26mm(半径差 13mm),完全没有牙可以咬合 ✗

  若把 CC 直接放进花盆底座:径向间隙 1.6mm,只是"放进去",
  插 5mm 都 0 干涉 = 松配,会晃动,提起底座 CC 不会跟着走 ✗

=====================================================================
五、可行方案(只改花盆底座,CC 保持不动)
=====================================================================
  方案 A(推荐):花盆底座内孔加【内伸凸台 + 内螺纹】
    在内孔里做一圈向内的凸台,把有效孔径从 Ø164.4 收到 Ø136.5
    再在内表面车出与 CC 顶部匹配的螺纹(牙深 1.3、螺距 4.8、留 0.3 间隙)
    → 花盆底座直接旋在 CC 顶部螺纹上,替掉原盖子
    → 优点:真正螺旋连接、可反复拆装;CC 一点不动 ✅
    → 注意:凸台与内孔要圆滑过渡,打印时凸台根部加 R1 圆角防裂

  方案 B:花盆底座做【卡口】
    内孔加 3 个 L 形凸耳,插到底转 30° 锁住
    → 打印容错最大,但需要 CC 上有对应的卡爪(CC 不能改 ✗)→ 不可行

  方案 C:花盆底座做【过渡转接环】
    单独打印一个 Ø136.5→Ø164 的转接环,环内螺纹配 CC,环外压入花盆底座
    → 不动机身,但多一个零件

  ★ 要让 CC 的螺纹真正被用上,方案 A 是唯一只在花盆底座上改动的做法
