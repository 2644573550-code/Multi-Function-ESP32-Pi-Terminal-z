打印误差冗余核算
=====================================================================
问题:有没有留打印误差冗余?
回答:留了,而且可以量化。三档整件的冗余如下,并给出推荐档位。

=====================================================================
一、三档整件的实际间隙
=====================================================================
  档位      文件                                  单边间隙   适用情况
  1.000    Pot_Base_FINAL_内壁3mm_倒角优化.stl     **0.45mm**  标准(CC 尺寸准)
  1.005    Pot_Base_v2_放大1005_内壁3mm.stl        0.79mm    推荐(留足冗余)
  1.010    Pot_Base_FINAL_放大101.stl              **1.12mm**  备用(CC 偏大)

  说明:间隙 = 建模时的 0.45mm 基准 + XY 放大量
        1.000 → +0.00 → 0.45mm
        1.005 → +0.34 → 0.79mm
        1.010 → +0.67 → 1.12mm

=====================================================================
二、打印误差到底有多大(逐项列出)
=====================================================================
  误差源                              对单边间隙的影响
  ─────────────────────────────────────────────────
  CC 已打印件的收缩(PLA 0.2~0.4%)      ±0.14 ~ 0.28mm
    (Ø138 螺纹,收缩 0.2% = 0.28mm 直径 = 0.14mm 半径)
  H2D 的 XY 定位精度                    ±0.10mm
  0.12mm 层高的牙侧阶梯                 ±0.06mm
  挤出流量偏差(±3%)                    ±0.04mm
  ─────────────────────────────────────────────────
  合计(最坏叠加)                       约 ±0.48mm

  ★ 结论:最坏情况会吃掉 0.48mm 的间隙。

=====================================================================
三、三档够不够(冗余判定)
=====================================================================
  档位      设计间隙   最坏吃掉   剩余      判定
  1.000    0.45mm    0.48mm    **-0.03mm** ⚠ 可能装不进
  1.005    0.79mm    0.48mm    **+0.31mm** ✅ 推荐
  1.010    1.12mm    0.48mm    **+0.64mm** ✅ 偏松

  → 1.000 在最坏情况下会卡住(间隙被吃光)
  → 1.005 留了 0.31mm 净余量,是最合理的平衡点
  → 1.010 余量 0.64mm,偏松(会有轻微晃动)

  补充:如果 CC 的实际尺寸比名义小(收缩),情况会更好;
        如果 CC 反而偏大(挤出过量),1.000 一定装不进。

=====================================================================
四、为什么 1.010 会偏松
=====================================================================
  1.12mm 单边间隙对应的牙侧轴向游隙 ≈ 1.12 / tan(60°) × 2 ≈ 1.3mm
  → 花盆放上去会有轻微"摇晃感",但螺纹仍然自锁(导程角 0.59° ≪ 摩擦角 19.3°)
  → 实际使用没问题(花盆不靠底座定位精度),只是手感偏松

=====================================================================
五、结论与建议
=====================================================================
  ✅ 冗余留了(1.005 留 0.31mm,1.010 留 0.64mm)
  ✅ 最坏情况下 1.005 仍然可装
  ✅ 1.010 作为"CC 偏大"的保险档
  ⚠ 1.000 不要直接打 —— 最坏情况会卡住

  推荐执行:
    1) 先打 三档试环(30 分钟),看 CC 实际偏大还是偏小
    2) 若 CC 偏小/正常  → 用 1.005 整件
    3) 若 CC 偏大        → 用 1.010 整件
    4) 1.000 仅在实测确认 CC 尺寸很准时才用

  另外,切片时建议:
    · 首层流量 -2%        → 防象脚,避免螺纹入口被撑大
    · 外墙优先            → 保牙面精度
    · 关闭"随机接缝"→ 改"对齐接缝",避免接缝落在牙面上

=====================================================================
六、一句话
=====================================================================
  留了。最坏打印误差约 ±0.48mm:
    1.000 档(0.45mm)可能被吃光 ✗
    1.005 档(0.79mm)净余 0.31mm ✅ 推荐
    1.010 档(1.12mm)净余 0.64mm ✅ 偏松备用
=====================================================================
