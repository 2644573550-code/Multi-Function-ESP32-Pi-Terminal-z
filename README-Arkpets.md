# 桌宠彩蛋（Arkpets）

本项目 `pi_terminal` 包含原生 Qt/QML 桌宠功能；桌宠默认关闭，不自动启动。

## 打开阿米娅预览

```sh
bash pi_terminal/scripts/run-arkpets-preview.sh
```

已实现任务栏上行走、坐下、躺下、点击互动、边界转向与拖拽释放后的重力/惯性下落。右键或长按人物可切换动作，平时自动交替活动；人物显示于终端内普通应用窗口上方。角色管理可搜索下载 Ark-Models 基建角色，在运行设备后台自动转换后切换；失败保留当前角色。旧下载角色可点击“升级动作”增加可用姿势。

桌宠作为隐藏彩蛋，程序每次启动默认关闭且不加载人物图集。在设置中连续点击“显示与个性化”标题 5 次（相邻点击间隔不超过 1.8 秒），弹出“启动/关闭桌宠”和“桌宠管理”两项。打开管理不会自动启动桌宠；角色、大小与画质偏好仍保留。

管理界面使用系统应用共用 Theme 配色、字体、圆角与最大化/恢复、关闭按钮，保留 Material 3 的“角色 → 默认/服装模型”分类列表；宽屏双栏、窄屏逐级浏览。

标题栏放大镜按钮打开“大小与画质”：大小 50%～200% 即时预览；质量提供流畅 128px、标准 256px、高清 384px。选择质量后在模型列表点“更新质量/动作”重新转换，不是把低清图片简单放大。角色按可见待机高度归一化，逐帧贴合任务栏。

技术说明、完整终端启动方法及本机测试命令见 [docs/arkpets-local.md](docs/arkpets-local.md)。
