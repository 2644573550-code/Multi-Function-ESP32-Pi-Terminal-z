# Offline pinyin dictionaries

The keyboard combines a frequency-ranked character dictionary with a broad
phrase dictionary. It generates phrase candidates locally by pinyin, then
falls back to combinations from the character table; it does not use a
hand-written word list or network lookup.

## Character table

- Upstream: Rime `rime-pinyin-simp`, derived from Android Pinyin IME.
- Source: `https://raw.githubusercontent.com/rime/rime-pinyin-simp/master/pinyin_simp.dict.yaml`
- SHA-256: `e341598343a0f0f2035bb1aafc34a7f3bb7887deeecb3f60796262aaa2983e6b`
- License/attribution: Apache License 2.0; see `LICENSE` and `AUTHORS`.

## Phrase table

- Upstream data: PyPinyin `phrases_dict.json`, 47,111 phrase entries.
- Source: `https://github.com/mozillazg/python-pinyin`, PyPinyin 0.55.0.
- Source SHA-256: `a45ff140a6b631ca9c82127b280a2f414e0aba6bb2824a0e9d1e77fff359c665`
- License: MIT; see `PYPINYIN-LICENSE`.
- `phrases.tsv` is generated by `tools/build_pinyin_dictionary.py`; it removes
  tone marks, uses keyboard `v` for ü, and ranks phrase candidates using the
  character-frequency table. The generated table SHA-256 is
  `3d7087e4b240e3e94eb9151ff99c660bb43f202129873215e735e0cc4a742421`.

Run `python3 tools/build_pinyin_dictionary.py` to regenerate the phrase table.
# Frequency ranking (2026-10-14)

`jieba-dict.txt` is the unmodified `jieba/dict.txt` from
https://github.com/fxsjy/jieba (retrieved 2026-10-14), licensed under MIT;
see `JIEBA-LICENSE`. Its word frequencies replace the previous character-sum
heuristic for phrase ranking. Rime character frequencies remain the fallback.
The full-pinyin lattice combines dictionary words and syllables using
log-frequency token scores; explicit candidate selections add a bounded,
persisted usage bonus. No double-pinyin scheme is exposed.
